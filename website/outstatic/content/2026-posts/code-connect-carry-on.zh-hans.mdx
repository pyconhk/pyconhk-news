## 大会议程

### 第一天 — 大会日：2026 年 11 月 14 日

PyCon HK 2026 大会日设有三条演讲主线，涵盖 Python、人工智能、数据、软件工程及社区等多个领域。精选环节包括：

#### \[主题演讲] Paul Everitt：Was, Is, Will Be: Python History, Software Engineering, And AI Our Way

Paul Everitt 是 JetBrains 的开发者推广专员，也是 Zope Corporation 的共同创办人。他将回顾 Python 的发展历程，并探讨社区的凝聚力如何推动 Python 持续发展。

演讲还将探讨代理式编程（Agentic Coding）如何改变软件开发行业及社区，以及我们如何通过一个专为 Python 社区打造的人工智能项目，共同塑造未来。

#### Jacky Chan：人工智能听到声音时，会联想到什么？

Jacky Chan 是一位香港研究员，致力于开发及测试本地人工智能系统。他将探讨多模态模型如何根据声音建立联想。

通过使用原始音频及不同提示词（Prompts）进行实验，他将展示不同模型之间的差异，并探讨人工智能评估及比较方面的新可能性。

#### Hon Kwan Shun Quinson：Property-Based Testing with Hypothesis

Hon Kwan Shun Quinson 是香港中文大学计算机科学系的哲学硕士（M.Phil.）研究生，将探讨大型语言模型（LLM）在软件开发中的应用。

参与者将了解如何运用 Hypothesis 进行基于属性的测试（Property-Based Testing），通过自动生成有结构的测试输入，覆盖更广泛的测试场景，从而提升对 Python 代码可靠性的信心。

#### Indy Ho：Python Applications in Sports Science, Injury Prevention and Physical Fitness Promotion

Indy Ho 是香港高等教育科技学院（THEi）的物理治疗师及助理教授。他将介绍 Python 在运动科学、伤患预防及人体运动表现研究中的应用。

参与者将了解如何利用生物力学数据进行预测分析，并通过实例及 YOLO-Pose 现场演示，探索人体姿态估计技术的应用。

更多节目安排及演讲详情，请浏览：**[PyCon HK 2026 节目时间表](https://www.pycon.hk/2026/en/schedule/)**
