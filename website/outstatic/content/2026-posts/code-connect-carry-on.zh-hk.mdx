## PyCon HK 2026

**活動場地：** 香港資訊科技學院（HKIIT），位於職業訓練局李惠利分校（將軍澳）。

**第一日 — 大會日（Conference Day）：** 2026 年 11 月 14 日 — 設有三條演講主線，仲有社群活動同展位，等大家交流同認識更多開源項目。[立即報名！](https://www.eventbrite.hk/e/pycon-hk-2026-tickets-1998483131845)

**第二日 — 開發衝刺日（Development Sprint）：** 2026 年 11 月 15 日 — 同其他參加者一齊協作，開發 Python 同開源項目。[立即報名！](https://www.eventbrite.hk/e/pycon-hk-2026-tickets-1998483131845)，仲可以[提交項目提案，或者報名做衝刺日領隊！](https://cfp.pycon.hk/pyconhk2026/cfp)

PyCon HK 2026 係香港一年一度嘅重要 Python 技術盛會，亦係全球每年舉辦嘅 50 多場 PyCon 活動之一。今年嘅大會由[香港 Python 用戶組（Hong Kong Python User Group）](https://www.facebook.com/groups/hkpug)、[香港開源社群（Open Source Hong Kong，OSHK）](https://opensource.hk/)、[香港創意開放科技協會（Hong Kong Creative Open Technology Association，HKCOTA）](https://hkcota.org/) 同 [香港資訊科技學院（HKIIT）](https://hkiit.edu.hk/) 聯合主辦。

今年大會嘅主題係 **「編程・連結・前行」（Code, Connect and Carry On）**，希望展現香港 Python 社群喺 AI 時代入面迎難而上、繼續向前嘅精神。

Python 一直喺人工智能、自動化同創新發展方面發揮重要作用。我哋聚埋一齊，探索點樣負責任咁運用呢啲急速發展嘅技術，同時堅持以人為本，令科技真正服務大眾。

歡迎大家喺 2026 年 11 月 14 日嚟到將軍澳香港資訊科技學院，一齊參與呢場充滿啟發嘅盛會，聽精彩演講、體驗實際應用，同其他社群成員交流。第二日，即係 11 月 15 日，我哋仲會舉行開發衝刺日，繼續一齊交流同開發項目。

就等我哋一齊實踐 **「編程・連結・前行」** 嘅精神，擁抱 Python 同 AI，發揮堅毅不屈嘅精神，攜手向前！

## 第一日 — 大會日：2026 年 11 月 14 日

PyCon HK 2026 大會日設有三條演講主線，內容涵蓋 Python、人工智能、數據、軟件工程同社群等唔同範疇。精選演講包括：

### \[主題演講] Paul Everitt：Was, Is, Will Be: Python History, Software Engineering, And AI Our Way

Paul Everitt 係 JetBrains 嘅開發者推廣專員，亦係 Zope Corporation 嘅共同創辦人。

佢會帶大家回顧 Python 嘅發展歷程，了解 Python 社群嘅凝聚力點樣推動呢門語言持續發展。演講亦會探討代理式編程（Agentic Coding）點樣改變軟件開發行業同社群，以及我哋可以點樣透過一個專為 Python 社群而設嘅 AI 項目，一齊塑造未來。

### Jacky Chan：AI 聽到聲音時，會聯想到乜嘢？

Jacky Chan 係一位香港研究員，專門建立同測試本地 AI 系統。

佢會探討多模態模型點樣理解聲音，以及點樣根據聲音產生聯想。透過使用原始音訊同唔同提示詞（Prompts）進行實驗，佢會展示唔同模型之間嘅差異，並探討 AI 評估同比較方面有咩新可能。

### Hon Kwan Shun Quinson：Property-Based Testing with Hypothesis

Hon Kwan Shun Quinson 係香港中文大學計算機科學系嘅哲學碩士（M.Phil.）研究生，今次會探討大型語言模型（LLM）喺軟件開發方面嘅應用。

你會了解到點樣運用 Hypothesis 進行基於屬性嘅測試，透過自動生成有結構嘅測試輸入，測試更多唔同情況，從而提高 Python 程式碼嘅可靠性。

### Indy Ho：Python Applications in Sports Science, Injury Prevention and Physical Fitness Promotion

Indy Ho 係香港高等教育科技學院（THEi）嘅物理治療師兼助理教授。

佢會介紹 Python 喺運動科學、傷患預防同人體運動表現研究方面嘅應用。你可以了解點樣利用生物力學數據進行預測分析，亦可以透過實際例子同 YOLO-Pose 即場示範，認識人體姿態估計技術嘅應用。

想了解更多節目安排同演講詳情，可以瀏覽：[PyCon HK 2026 節目時間表](https://www.pycon.hk/2026/en/schedule/)
