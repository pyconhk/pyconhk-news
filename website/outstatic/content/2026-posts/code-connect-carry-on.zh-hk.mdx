#### 〔長版〕

PyCon HK 2026 係香港最具代表性嘅 Python 技術盛會，亦係全球每年舉辦嘅 50 多場 PyCon 活動之一，今年已經踏入第 12 年。今屆大會以**「編程・連結・前行」（Code, Connect and Carry On）**為主題，展現香港 Python 社群喺人工智能時代迎難而上、持續發展嘅精神。

隨住 Python 持續推動人工智能、自動化同科技創新，數據科學家、開發者、工程師、分析師、教育工作者同學生將會聚首一堂，一齊探討點樣以負責任嘅方式應用呢啲發展迅速嘅技術，同時堅守以人為本嘅理念，等科技真正服務大眾。我哋相信，Python 同 AI 可以雙劍合璧，發揮無限創造力，等我哋把握機遇，攜手締造以人為本嘅科技時代。

歡迎所有對 AI、Python 或者科技有興趣嘅朋友，喺 2026 年 11 月 14 日嚟到將軍澳香港資訊科技學院，參與呢場集合精彩演講、實踐體驗同社群交流嘅盛會。衝刺開發日會喺第二日（11 月 15 日）接住舉行。等我哋一齊實踐「編程・連結・前行」嘅精神，擁抱 Python 同人工智能，以堅毅不屈嘅態度攜手向前。

## 大會議程

### 2026 年 11 月 14 日｜第一日 — 會議日（Conference Day）

PyCon HK 2026 會議日設有三條演講主線，涵蓋 Python、人工智能、數據、軟件工程同社群等多個範疇。精選環節包括：

#### ［主題演講］Paul Everitt：Was, Is, Will Be: Python History, Software Engineering, And AI Our Way

Paul Everitt 係 JetBrains 嘅開發者推廣專員，亦係 Zope Corporation 嘅共同創辦人。佢會帶大家回顧 Python 嘅發展歷程，探討社群嘅凝聚力點樣推動 Python 持續發展。

演講亦會探討代理式編程（Agentic Coding）點樣改變軟件開發行業同社群，以及我哋可以點樣透過一個專為 Python 社群而設嘅人工智能項目，一齊塑造未來。

#### Jacky Chan：人工智能聽到聲音嗰陣，會聯想到啲乜？

Jacky Chan 係一位香港研究員，專注開發同測試本地人工智能系統。佢會探討多模態模型點樣根據聲音建立聯想。

透過用原始音訊同唔同提示詞（Prompts）做實驗，佢會展示唔同模型之間嘅差異，並探討評估同比較人工智能模型嘅新可能。

#### Hon Kwan Shun Quinson：Property-Based Testing with Hypothesis

Hon Kwan Shun Quinson 係香港中文大學計算機科學系嘅哲學碩士（M.Phil.）研究生，佢會探討大型語言模型（LLM）喺軟件開發上嘅應用。

參加者會了解到點樣運用 Hypothesis 做基於屬性嘅測試，透過自動產生有結構嘅測試輸入，涵蓋更多唔同嘅測試情境，從而對 Python 程式碼嘅可靠性更有信心。

#### Indy Ho：Python Applications in Sports Science, Injury Prevention and Physical Fitness Promotion

Indy Ho 係香港高等教育科技學院（THEi）嘅物理治療師同助理教授。佢會介紹 Python 喺運動科學、傷患預防同人體運動表現研究上嘅應用。

參加者會了解到點樣利用生物力學數據做預測分析，並透過實例同 YOLO-Pose 即場示範，探索人體姿態估計技術嘅應用。
