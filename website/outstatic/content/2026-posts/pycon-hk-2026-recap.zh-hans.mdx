## 冲刺开发成果

### nsh-py

GitHub 记录显示，nsh-py 在冲刺开发日合并了 16 个标记为 PyCon HK 2026 的拉取请求，包括徽章和标签页组件、macOS 的 Ctrl-C 修复，以及 Kanban 看板示例。

![nsh-py 冲刺开发演示文稿展示原生应用组件](/outstatic/images/pyconhk2026-sprint-nsh.webp)

[查看成果演示文稿（PDF）](https://drive.google.com/file/d/1VNg6nnTYm7WSm5XWWA3hZLDqKuyYhmau/view) · [查看已合并的拉取请求](https://github.com/lucianosrp/nsh-py/pulls?q=is%3Apr+is%3Amerged+label%3Apycon-hk-26)

### 使用 MiniMind 训练大型语言模型

团队为 MiniMind 添加了 Apple MPS 支持，实践了语言模型的预训练和监督微调，并展示了模型回答区块链问题的示例。

![MiniMind 幻灯片列出从 Apple MPS 支持到监督微调的工作](/outstatic/images/pyconhk2026-sprint-minimind.webp)

[查看成果演示文稿（PDF）](https://drive.google.com/file/d/1I9auW_lJHE9LMgpmeCDUNdNrYq1HugGy/view)

### Django 代码与测试

一位初次接触 Django 的参与者跟随 Django Girls 教程，在本机启动了开发服务器。团队搭建了 Django 开发环境，并提交了文档拉取请求，说明如何在独立 Python 脚本中使用 Django ORM。

![Django 幻灯片介绍在独立 Python 脚本使用 ORM 的文档任务](/outstatic/images/pyconhk2026-sprint-django.webp)

[查看 Django 两组共用演示文稿（PDF）](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=4) · [查看文档拉取请求](https://github.com/django/django/pull/22291)

### Django 文档翻译

Django 在 Transifex 的文档翻译项目新增了香港繁体中文（`zh_HK`）。团队提名了两位志愿者担任协调员，Django 维护者随后确认两人均可管理翻译团队。

![Django 冲刺更新幻灯片显示 Transifex 已加入香港繁体中文](/outstatic/images/pyconhk2026-sprint-django-translation.webp)

[查看 Django 两组共用演示文稿（PDF）](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=5) · [查看 Django 论坛更新](https://forum.djangoproject.com/t/question-about-traditional-chinese-hong-kong-zh-hk-documentation-translations/46413/5)

### 用决策模型标注视频

团队开发了逐帧视频标注工具，以及桌面版和网页版图片工具。标注问题集中保存在 YAML 文件中，方便使用者直接修改。团队还演示了逐帧标注流程。

![幻灯片列出逐帧标注工具、桌面版和网页版工具，以及 YAML 问题文件](/outstatic/images/pyconhk2026-sprint-video.webp)

[查看成果演示文稿（PDF）](https://drive.google.com/file/d/1R_FulVe5KEfg1KlPfNcikqBosnEEBcAu/view) · [查看标注工具源代码](https://github.com/dev1virtuoso/Event/commit/c20fe9dcd668375b5d96d294c182258067529851)
