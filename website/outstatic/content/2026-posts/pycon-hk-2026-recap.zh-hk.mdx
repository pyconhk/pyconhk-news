## 衝刺開發成果

### nsh-py

GitHub 記錄顯示，nsh-py 喺 Sprint Day 合併咗 16 個標記為 PyCon HK 2026 嘅 PR，包括徽章同分頁元件、macOS 嘅 Ctrl-C 修正，以及 Kanban 看板範例。

![nsh-py 衝刺開發簡報，展示原生應用程式元件](/outstatic/images/pyconhk2026-sprint-nsh.webp)

[睇成果簡報（PDF）](https://drive.google.com/file/d/1VNg6nnTYm7WSm5XWWA3hZLDqKuyYhmau/view) · [睇已合併嘅 PR](https://github.com/lucianosrp/nsh-py/pulls?q=is%3Apr+is%3Amerged+label%3Apycon-hk-26)

### 用 MiniMind 訓練大型語言模型

小組為 MiniMind 加入 Apple MPS 支援，嘗試為語言模型做預訓練同監督式微調，並展示模型回答區塊鏈問題嘅例子。

![MiniMind 簡報列出由 Apple MPS 支援到監督式微調嘅工作](/outstatic/images/pyconhk2026-sprint-minimind.webp)

[睇成果簡報（PDF）](https://drive.google.com/file/d/1I9auW_lJHE9LMgpmeCDUNdNrYq1HugGy/view)

### Django 程式碼同測試

有首次接觸 Django 嘅參加者跟住 Django Girls 教學，喺自己部機開到開發伺服器。小組一齊設定 Django 開發環境，並開咗一個文件 PR，說明點樣喺獨立 Python 腳本使用 Django ORM。

![Django 簡報介紹獨立 Python 腳本使用 ORM 嘅文件任務](/outstatic/images/pyconhk2026-sprint-django.webp)

[睇 Django 兩組共用簡報（PDF）](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=4) · [睇文件 PR](https://github.com/django/django/pull/22291)

### Django 文件翻譯

Django 喺 Transifex 嘅文件翻譯項目新增咗香港繁體中文（`zh_HK`）。小組提名兩位義工做協調員，Django 維護者其後確認兩位都可以管理翻譯團隊。

![Django 衝刺更新投影片顯示 Transifex 已加入香港繁體中文](/outstatic/images/pyconhk2026-sprint-django-translation.webp)

[睇 Django 兩組共用簡報（PDF）](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=5) · [睇 Django 論壇更新](https://forum.djangoproject.com/t/question-about-traditional-chinese-hong-kong-zh-hk-documentation-translations/46413/5)

### 用決策模型標註影片

團隊做咗一個逐格影片標註工具，同埋桌面版同網頁版圖片工具。標註問題放喺 YAML 檔，可以就咁改問題。團隊亦示範咗逐格標註嘅流程。

![投影片列出逐格標註工具、桌面版同網頁版工具，以及 YAML 問題檔](/outstatic/images/pyconhk2026-sprint-video.webp)

[睇成果簡報（PDF）](https://drive.google.com/file/d/1R_FulVe5KEfg1KlPfNcikqBosnEEBcAu/view) · [睇標註工具原始碼](https://github.com/dev1virtuoso/Event/commit/c20fe9dcd668375b5d96d294c182258067529851)
