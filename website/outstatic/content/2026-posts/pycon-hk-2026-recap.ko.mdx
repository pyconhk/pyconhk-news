PyCon HK 2026은 정관오의 홍콩정보기술학원(HKIIT)에서 11월 14일에 컨퍼런스, 15일에 개발 스프린트를 열었습니다. 발표하고, 아이디어를 나누고, 프로젝트에 기여하고, 행사 운영을 도와주신 모든 분께 감사드립니다.

## 개발 스프린트 성과

### nsh-py

GitHub 기록에 따르면 스프린트 당일 PyCon HK 2026 태그가 붙은 풀 리퀘스트 16건이 병합됐습니다. 배지와 탭 컴포넌트, macOS의 Ctrl-C 문제 수정, 칸반 보드 예제가 포함됩니다.

![네이티브 앱 컴포넌트를 보여 주는 nsh-py 스프린트 발표 자료](/outstatic/images/pyconhk2026-sprint-nsh.webp)

[발표 자료 보기(PDF)](https://drive.google.com/file/d/1VNg6nnTYm7WSm5XWWA3hZLDqKuyYhmau/view) · [병합된 풀 리퀘스트 보기](https://github.com/lucianosrp/nsh-py/pulls?q=is%3Apr+is%3Amerged+label%3Apycon-hk-26)

### MiniMind로 대규모 언어 모델 학습하기

팀은 MiniMind에 Apple MPS 지원을 추가하고 언어 모델 사전 학습과 지도 미세 조정을 진행했습니다. 블록체인 관련 질문에 대한 모델 응답 예시도 소개했습니다.

![Apple MPS 지원부터 지도 미세 조정까지의 작업을 정리한 MiniMind 슬라이드](/outstatic/images/pyconhk2026-sprint-minimind.webp)

[발표 자료 보기(PDF)](https://drive.google.com/file/d/1I9auW_lJHE9LMgpmeCDUNdNrYq1HugGy/view)

### Django 코드와 테스트

Django를 처음 접한 참가자가 Django Girls 튜토리얼을 따라 로컬 개발 서버를 실행했습니다. 팀은 개발 환경을 구성하고, 독립 실행형 Python 스크립트에서 Django ORM을 사용하는 방법을 설명하는 문서 풀 리퀘스트를 열었습니다.

![독립 실행형 Python 스크립트에서 ORM을 사용하는 방법에 관한 문서 작업을 설명하는 Django 슬라이드](/outstatic/images/pyconhk2026-sprint-django.webp)

[Django 두 팀의 공동 발표 자료 보기(PDF)](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=4) · [문서 풀 리퀘스트 보기](https://github.com/django/django/pull/22291)

### Django 문서 번역

Transifex의 Django 문서 번역 프로젝트에 홍콩 번체 중국어(`zh_HK`)가 추가됐습니다. 팀은 자원봉사자 두 명을 코디네이터로 추천했고, Django 관리자는 두 사람이 번역 팀을 관리할 수 있게 됐다고 확인했습니다.

![Transifex에 홍콩 번체 중국어가 추가됐음을 보여 주는 Django 슬라이드](/outstatic/images/pyconhk2026-sprint-django-translation.webp)

[Django 두 팀의 공동 발표 자료 보기(PDF)](https://docs.google.com/presentation/d/17z8ocS76H6CQkF7daQOVdXD3ytAfM3Hw/export/pdf#page=5) · [Django 포럼 업데이트 보기](https://forum.djangoproject.com/t/question-about-traditional-chinese-hong-kong-zh-hk-documentation-translations/46413/5)

### 의사결정 모델을 활용한 영상 태깅

팀은 영상 프레임 단위의 어노테이션 도구와 데스크톱 및 웹 이미지 도구를 만들었습니다. 질문을 YAML 파일에 넣어 쉽게 바꿀 수 있게 했으며, 영상 프레임에 태그를 다는 과정을 시연했습니다.

![영상 프레임 어노테이션, 데스크톱 및 웹 이미지 도구, YAML 질문 파일을 소개하는 슬라이드](/outstatic/images/pyconhk2026-sprint-video.webp)

[발표 자료 보기(PDF)](https://drive.google.com/file/d/1R_FulVe5KEfg1KlPfNcikqBosnEEBcAu/view) · [어노테이션 도구 소스 보기](https://github.com/dev1virtuoso/Event/commit/c20fe9dcd668375b5d96d294c182258067529851)
